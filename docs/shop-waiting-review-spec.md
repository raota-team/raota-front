# 가게 상세 웨이팅 기록 명세 초안

## 1. 목적

가게 상세 페이지에서 방문자가 실제로 도착한 요일, 도착 시간, 기다린 시간을 모아, 다음 방문자가 요일과 시간대별 대기 흐름을 빠르게 판단할 수 있게 한다.

이 기능은 긴 리뷰가 아니라 방문 판단용 짧은 데이터에 집중한다.

## 2. 화면 위치

PC:

- 가게 상세 오른쪽 사이드바에 배치한다.
- `가게 정보` 카드 아래에 둔다.
- 이후 `메뉴 투표`, `라멘로그 미리보기`가 이어진다.

모바일:

- 본문 상단의 `먹은 라멘 기록하기` CTA와 `가게 정보` 카드 아래에 배치한다.
- 모바일에서는 `가게 정보`를 먼저 확인한 뒤 웨이팅 흐름을 볼 수 있게 한다.

## 3. 표시 정보

### 3.1 요약

카드 상단에는 선택한 요일 기준의 웨이팅 기록 요약을 표시한다.

| 항목 | 설명 |
| --- | --- |
| 선택 요일 평균 | 선택한 요일의 평균 대기 시간 |
| 선택 요일 기록 | 선택한 요일의 웨이팅 기록 수 |

### 3.2 요일 필터

요일 필터는 `일 월 화 수 목 금 토` 7개 버튼으로 제공한다.

기본값:

- 오늘 요일을 기본 선택한다.
- 오늘 요일 계산은 한국 시간(`Asia/Seoul`) 기준이다.
- 오늘 요일 버튼에는 작은 점 표시를 둔다.
- 오늘 요일 안내 문구는 별도로 노출하지 않는다.

### 3.3 도착시간 필터

도착시간 필터는 커스텀 드롭다운으로 제공한다.

기본값:

```text
전체 시간대 · N개
```

`N`은 현재 선택한 요일에 해당하는 기록 수이다.

드롭다운 항목:

- 전체 시간대
- 선택한 요일 안의 도착시간별 항목

도착시간별 항목은 다음 형식으로 표시한다.

```text
11:35    평균 18분 · 1개
12:20    평균 42분 · 1개
```

도착시간 항목이 많아져도 카드가 가로로 늘어나지 않도록 칩 리스트는 사용하지 않는다.

## 4. 리스트

웨이팅 기록은 하나씩 크게 보여주지 않고, 리스트로 여러 개를 보여준다.

리스트 row 표시 항목:

| 항목 | 설명 |
| --- | --- |
| 요일 | 기록의 방문 요일 |
| 도착 시간 | 사용자가 가게에 도착한 시간 |
| 대기 시간 | 도착 후 입장까지 기다린 시간 |
| 작성자 | 기록 작성자 |
| 작성일 | 기록 작성 날짜 |

예시:

```text
목요일 · 도착 11:35
멘마수집가 · 2026-07-05      대기 18분
```

리스트는 카드 안에서 여러 개를 한 번에 보여준다.

현재 프론트 기준:

- 한 페이지에 4개 표시
- 항목이 5개 이상이면 리스트 하단에 이전/다음 버튼 표시
- 페이지 표기는 `현재 페이지/전체 페이지` 형식
- 페이지 전체 가로 overflow는 없어야 한다.

페이징 예:

```text
이전    1/3    다음
```

첫 페이지에서는 `이전` 버튼을 비활성화한다.

마지막 페이지에서는 `다음` 버튼을 비활성화한다.

## 5. 작성 CTA

카드 하단에는 `웨이팅 기록 남기기` CTA를 둔다.

CTA 클릭 시 작성 모달을 연다.

## 6. 작성 모달

작성 모달 입력 항목은 3개만 둔다.

| 항목 | 타입 | 설명 |
| --- | --- | --- |
| 요일 | button group | 방문 요일 |
| 도착 시간 | time | 사용자가 가게에 도착한 시간 |
| 기다린 시간 | number | 입장까지 기다린 시간, 분 단위 |

입력하지 않는 항목:

- 상황
- 짧은 후기
- 별점
- 메뉴 정보

웨이팅 기록은 맛 평가가 아니라 대기 데이터이므로 텍스트 후기를 받지 않는다.

## 7. 입력 제한

| 항목 | 제한 |
| --- | --- |
| 요일 | 필수 |
| 도착 시간 | 필수 |
| 기다린 시간 | 0분 이상 300분 이하 |

`기다린 시간`이 0분이면 화면에는 `바로 입장`으로 표시한다.

60분 이상은 시간 단위로 변환한다.

예:

| 값 | 표시 |
| --- | --- |
| 0 | 바로 입장 |
| 18 | 18분 |
| 75 | 1시간 15분 |
| 120 | 2시간 |

## 8. 접근 조건

조회:

- 로그인하지 않아도 볼 수 있다.

작성:

- 로그인한 사용자만 작성할 수 있다.
- 비로그인 사용자가 CTA를 통해 제출하면 로그인 이동 확인창을 띄운다.

## 9. 현재 프론트 구현 상태

현재 구현은 더미 데이터와 로컬 state 기반이다.

더미 데이터:

```ts
type WaitingReview = {
  id: number;
  user: string;
  dayOfWeek: "sun" | "mon" | "tue" | "wed" | "thu" | "fri" | "sat";
  arrivalTime: string;
  waitMinutes: number;
  createdAt: string;
};
```

작성 후 동작:

- 새 기록을 리스트 맨 위에 추가
- 작성한 요일을 자동 선택
- 작성한 도착시간을 자동 선택
- 리스트 페이지를 첫 페이지로 이동
- 작성 모달 닫기
- 성공 toast 표시

새로고침하면 더미 기본값으로 돌아간다.

## 10. 향후 API 명세 초안

### 10.1 웨이팅 기록 조회

```http
GET /shops/{shopId}/waiting-reviews?dayOfWeek=thu&arrivalTime=11:35
```

Query:

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `dayOfWeek` | string | N | 요일 필터, 없으면 서버 기준 오늘 요일 또는 전체 정책 중 선택 |
| `arrivalTime` | string | N | 특정 도착시간 필터, 없으면 선택 요일의 전체 |

응답:

```json
{
  "status": "SUCCESS",
  "message": "성공",
  "data": {
    "summary": {
      "averageWaitMinutes": 30,
      "totalCount": 2,
      "dayOfWeek": "thu"
    },
    "timeBuckets": [
      {
        "arrivalTime": "11:35",
        "averageWaitMinutes": 18,
        "count": 1
      },
      {
        "arrivalTime": "12:20",
        "averageWaitMinutes": 42,
        "count": 1
      }
    ],
    "items": [
      {
        "id": 1,
        "user": {
          "id": 12,
          "nickname": "멘마수집가"
        },
        "dayOfWeek": "thu",
        "arrivalTime": "11:35",
        "waitMinutes": 18,
        "createdAt": "2026-07-05"
      }
    ]
  }
}
```

### 10.2 웨이팅 기록 작성

```http
POST /shops/{shopId}/waiting-reviews
Authorization: Bearer {token}
Content-Type: application/json
```

요청:

```json
{
  "dayOfWeek": "thu",
  "arrivalTime": "12:00",
  "waitMinutes": 20
}
```

응답:

```json
{
  "status": "SUCCESS",
  "message": "저장되었습니다.",
  "data": {
    "id": 3,
    "dayOfWeek": "thu",
    "arrivalTime": "12:00",
    "waitMinutes": 20,
    "createdAt": "2026-07-07"
  }
}
```

## 11. 검수 기준

- PC에서 웨이팅 기록 카드는 오른쪽 사이드바에 표시된다.
- 모바일에서는 본문 흐름 안에 표시된다.
- 오늘 요일이 기본 선택된다.
- 요일 선택 시 평균 대기, 기록 수, 도착시간 드롭다운, 리스트가 선택 요일 기준으로 바뀐다.
- 도착시간 필터는 드롭다운으로 표시된다.
- 도착시간 항목이 늘어나도 카드가 가로로 길어지지 않는다.
- 선택한 요일과 도착시간에 맞는 기록만 리스트에 표시된다.
- 여러 기록을 한 화면에서 리스트로 볼 수 있다.
- 기록이 5개 이상이면 이전/다음 버튼으로 페이지를 넘길 수 있다.
- 작성 모달은 요일, 도착 시간, 기다린 시간만 입력받는다.
- 상황, 후기 텍스트, 별점 입력은 없다.
- 비로그인 작성 시 로그인 이동 확인창이 표시된다.
