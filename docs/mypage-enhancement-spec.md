# 마이페이지 강화 기능 명세 초안

## 1. 목적

마이페이지를 단순 활동 목록이 아니라 사용자의 라멘로그 활동 흐름을 확인하는 개인 기록 대시보드로 확장한다.

이번 초안에서 다루는 범위:

- 프로필 영역 개선
- 라멘 활동 등급
- 라멘로그 캘린더
- 기록 요약
- 주간·월간 기록 목표 설정
- 남의 유저 프로필에서 공개 활동 정보 확인

월간 라멘 패스포트는 별도 탭 또는 별도 섹션으로 분리할 예정이며, 이 문서에서는 캘린더·요약·등급 중심으로 정리한다.

## 2. 화면 배치

### 2.1 전체 순서

마이페이지는 다음 순서로 구성한다.

1. 프로필 헤더
2. 이메일 정보 영역
3. 라멘 활동 등급
4. 라멘로그 캘린더 + 기록 요약
5. 활동 탭

활동 탭은 기존 구조를 유지한다.

- 내 로그
- 방문기록
- 게시글
- 댓글
- 북마크

북마크는 본인 프로필에서만 노출한다.

### 2.2 프로필 헤더

프로필 헤더는 PC와 모바일에서 모두 프로필 정보가 중심에 보이도록 정리한다.

표시 항목:

- 배경 이미지
- 프로필 이미지
- 닉네임
- 자기소개
- 프로필 수정 버튼
- 공개 설정 버튼

본인 프로필이 아닌 경우 수정·공개 설정 버튼은 노출하지 않는다.

### 2.3 이메일 정보

본인 프로필에서만 노출한다.

표시 항목:

- 이메일 주소
- 이메일 수정 버튼
- 수정 중 입력 필드
- 저장·취소 버튼

이메일 정보 아래에 라멘 활동 등급과 캘린더 섹션을 배치한다.

## 3. 라멘 활동 등급

### 3.1 목적

사용자가 라멘로그를 남기는 동기를 얻을 수 있도록 누적 라멘로그 개수 기반의 활동 등급을 보여준다.

### 3.2 등급 단계

| 등급 | 조건 |
| --- | --- |
| 라멘 입문자 | 0개 |
| 라멘을 즐기는 자 | 1개 이상 |
| 라멘집 탐험가 | 10개 이상 |
| 라멘집 단골 | 30개 이상 |
| 라멘 미식가 | 50개 이상 |
| 라멘 마스터 | 100개 이상 |

현재 구현은 `profile.stats.total_log_count`를 우선 사용하고, 없으면 `profile.stats.total_photo_count`를 보조로 사용한다.

### 3.3 UI 규칙

기본 화면에서는 현재 등급명만 간단히 보여준다.

등급 옆에는 `등급 안내` 버튼을 둔다. 버튼을 누르면 모달로 전체 등급 기준을 확인할 수 있다.

모달 표시 항목:

- 등급명
- 필요 라멘로그 개수
- 현재 등급 표시

## 4. 라멘로그 캘린더

### 4.1 목적

사용자가 라멘로그를 남긴 날과 기록 흐름을 한눈에 확인할 수 있도록 GitHub 활동 그래프와 유사한 캘린더를 제공한다.

화면 문구:

```text
라멘로그를 남긴 날과 기록 흐름을 한눈에 확인해요.
```

### 4.2 라이브러리

캘린더는 `react-activity-calendar`를 사용한다.

사용 이유:

- GitHub 스타일 활동 캘린더에 특화되어 있음
- 날짜별 activity data 모델을 그대로 받을 수 있음
- 월·요일 라벨, SVG grid 균형, tooltip 구조를 직접 구현하지 않아도 됨
- 모바일에서 가로 스크롤 패턴으로 다루기 좋음
- MIT 라이선스

### 4.3 기간 선택

기간 선택 옵션:

- 최근 1년
- 올해
- 작년
- 재작년

예시:

현재 날짜가 2026년 7월 7일이면 선택지는 다음과 같다.

- 최근 1년
- 2026
- 2025
- 2024

`최근 1년`은 오늘 기준 1년 전부터 오늘까지의 범위를 표시한다.

연도 선택은 해당 연도 1월 1일부터 12월 31일까지 표시한다. 다만 현재 연도가 선택된 경우 오늘 이후 날짜는 기록 수 0으로 표시하고 옅게 처리한다.

### 4.4 날짜별 데이터

캘린더 데이터 모델:

```ts
type Activity = {
  date: string;
  count: number;
  level: number;
};
```

필드 규칙:

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `date` | string | `YYYY-MM-DD` |
| `count` | number | 해당 날짜의 라멘로그 개수 |
| `level` | number | 표시 강도, 현재 0-3 |

현재 색상 단계:

| count | level | 색상 |
| --- | --- | --- |
| 0 | 0 | `#f2f2f2` |
| 1 | 1 | `#ffd6d6` |
| 2 | 2 | `#f15a5a` |
| 3 이상 | 3 | `#e60000` |

### 4.5 요약 문구

캘린더 하단에는 선택된 기간의 요약을 표시한다.

PC:

```text
2025년 7월 7일부터 2026년 7월 7일까지 라멘로그 176개
최근 기록일 7월 5일 · 이번 달 4일 동안 기록
```

모바일:

```text
2025년 7월 7일 - 2026년 7월 7일
라멘로그 176개
최근 기록일 7월 5일 · 이번 달 4일 동안 기록
```

### 4.6 반응형 규칙

PC:

- 캘린더 카드와 기록 요약 카드를 같은 행에 배치한다.
- 캘린더 카드와 기록 요약 카드의 높이는 맞춘다.
- 페이지 전체 가로 overflow는 발생하지 않아야 한다.

모바일:

- 기간 선택은 커스텀 드롭다운으로 표시한다.
- 캘린더 영역만 가로 스크롤 가능하게 한다.
- 페이지 전체가 좌우로 밀리면 안 된다.
- 캘린더 칸은 모바일에서도 너무 작아지지 않게 유지한다.

## 5. 기록 요약

### 5.1 목적

캘린더만으로 파악하기 어려운 핵심 지표를 별도 카드로 요약한다.

### 5.2 표시 항목

| 항목 | 설명 |
| --- | --- |
| 이번 달 | 이번 달 라멘로그 개수 |
| 올해 | 올해 라멘로그 개수 |
| 전체 | 전체 라멘로그 개수 |
| 기록한 날 | 이번 달 기록한 날짜 수 |
| 최근 기록일 | 가장 최근 기록한 날짜 |
| 주간 목표 | 이번 주 기록 목표 진행도 |
| 월간 목표 | 이번 달 기록 목표 진행도 |

`기록한 날`은 active day 기준이다. 하루에 여러 개를 기록해도 1일로 계산한다.

### 5.3 목표 진행도

주간 목표:

```ts
weeklyGoalProgress = min(100, thisWeekCount / weeklyGoalTarget * 100)
```

월간 목표:

```ts
monthlyGoalProgress = min(100, thisMonthCount / monthlyGoalTarget * 100)
```

목표 달성 수치는 `current/target` 형태로 표시한다.

예:

```text
주간 목표 1/1
월간 목표 4/4
```

## 6. 목표 설정

### 6.1 목적

사용자가 본인의 라멘로그 주간·월간 기록 목표를 간단하게 조정할 수 있게 한다.

### 6.2 접근 조건

목표 설정 버튼은 본인 프로필에서만 노출한다.

남의 프로필에서는 다음 정보는 볼 수 있다.

- 라멘 활동 등급
- 라멘로그 캘린더
- 기록 요약
- 주간·월간 목표 진행도

하지만 목표 설정 버튼은 숨긴다.

### 6.3 버튼 위치

기록 요약 카드 안에서 각 목표 항목 옆에 개별 설정 버튼을 둔다.

- `주간 목표` 옆 `설정`
- `월간 목표` 옆 `설정`

별도의 공통 목표 설정 버튼은 두지 않는다.

### 6.4 모달 동작

각 버튼은 자기 목표만 설정하는 모달을 연다.

`주간 목표` 설정 버튼:

- 주간 목표만 표시
- 주간 목표만 저장

`월간 목표` 설정 버튼:

- 월간 목표만 표시
- 월간 목표만 저장

모달 입력 UI:

- 감소 버튼
- 숫자 입력
- 증가 버튼
- 저장 버튼
- 취소 버튼

빠른 선택 버튼은 사용하지 않는다.

### 6.5 입력 제한

| 목표 | 최소값 | 최대값 | 기본값 |
| --- | --- | --- | --- |
| 주간 목표 | 1 | 14 | 1 |
| 월간 목표 | 1 | 60 | 4 |

입력값은 정수로 보정한다.

## 8. 현재 프론트 구현 상태

현재 구현은 일부 데이터가 더미 및 로컬 상태다.

### 8.1 더미 데이터

캘린더 날짜별 count는 `mockRamenLogActivity`와 날짜 기반 fallback 계산을 사용한다.

향후 실제 API로 교체해야 한다.

### 8.2 로컬 상태

주간·월간 목표는 현재 화면 로컬 state에 저장한다.

페이지를 새로고침하면 기본값으로 돌아간다.

향후 API 또는 사용자 설정 저장소로 전환해야 한다.

### 8.3 현재 추가 패키지

```json
{
  "react-activity-calendar": "^3.2.0"
}
```

## 9. 향후 API 명세 초안

```http

```

본인 조회:

```http
GET /users/me/ramen-log-activity?from=2025-07-07&to=2026-07-07
```

```json
  "message": "성공",
```

## 10. 검수 기준

### 10.1 기능

- 최근 1년 선택 시 오늘 기준 1년 전부터 오늘까지 표시된다.
- 연도 선택 시 해당 연도 전체가 표시된다.
- 현재 연도에서 오늘 이후 날짜는 count 0으로 처리된다.
- 캘린더 색상은 count가 많을수록 진한 빨간색으로 표시된다.
- 주간 목표 설정은 주간 목표만 수정한다.
- 월간 목표 설정은 월간 목표만 수정한다.
- 남의 프로필에서는 목표 설정 버튼이 보이지 않는다.

### 10.2 레이아웃

- PC에서 캘린더 카드와 기록 요약 카드의 높이가 맞는다.
- 모바일에서 캘린더만 가로 스크롤된다.
- 모바일에서 페이지 전체 가로 스크롤이 생기지 않는다.
- 캘린더 월 라벨과 요일 라벨이 칸을 덮거나 줄바꿈되지 않는다.
- 마지막 월 라벨이 카드 밖으로 잘리지 않는다.

### 10.3 접근성

- 캘린더 블록에는 날짜와 라멘로그 개수가 tooltip 또는 aria-label로 제공된다.
- 목표 설정 버튼에는 어떤 목표를 설정하는지 알 수 있는 `aria-label`이 있다.
- 모달 닫기 버튼에는 명확한 `aria-label`이 있다.
